# G-DATA-CORE v1 字段、来源、许可与 PIT 合同

更新时间：2026-07-20  
工作包：`L1-D3A`  
状态：`COMPLETE_CONTRACT_ONLY__NO_DATA_INGESTED`

## 1. 本合同完成什么

本目录把 `planned_datasets.json` 中 20 项 `G-DATA-CORE` 从“数据家族名称”展开为可实施的字段级合同：逻辑表、粒度、主键、字段类型、单位、主来源、校准来源、许可闸门、PIT 时间、修订规则、质量门和已知阻断。

本合同不表示数据已经下载，不创建空业务快照，不把公开网页自动解释为批量保存许可，也不把计划项写入实际 `datasets.json`。完成本合同后，核心数据库仍需经过 `L1-D12A` 发布骨架、端到端小样本、容量报告、历史回补和质量晋级。

## 2. 文件职责

- `contract.json`：总合同、全局时间/单位/缺失/许可规则、公共字段集和分组文件入口。
- `sources.json`：官方来源、适配器和内部派生来源登记；记录访问与批量采集闸门。
- `core_01_08_market_reference.json`：证券身份、日历、行情、公司行动、复权、交易状态、股本和估值。
- `core_09_12_index_industry.json`：指数主数据、历史成分权重、多口径行业和指数日行情。
- `core_13_20_fundamental_risk.json`：财务、业绩事件、审计、分红、主营、利率和基础风险描述子。
- `control/tools/validate_core_data_contract.py`：零第三方依赖的结构和交叉引用校验器。

`planned_datasets.json` 继续只管理范围和排期；`datasets.json` 继续只登记实际落盘且通过准入的资产。机器合同不得被 `qdata` 当作研究输入解析。

## 3. 已冻结的全局规则

1. 永久证券身份由 CORE-01 维护；股票代码、简称或当前上市状态不能充当跨历史主键。
2. 所有表继承 `record_lineage`，至少保存真正来源、来源记录、URL、`published_at`、`available_at`、`ingested_at`、`revision_id`、原文哈希、质量位、许可状态和 `snapshot_id`。
3. `available_at` 是决策时刻能否合法观察的唯一统一入口；报告期、基准日、生效日和本地抓取时间不得替代。
4. 未知保存为 `NULL + quality_flag`；不得填0。关键身份、单位、许可、PIT或覆盖缺失使批次进入 quarantine。
5. 来源冲突分别保留原值；canonical 值只能按已登记的字段级规则生成。
6. L1保存未复权价格、原始公告和修订链；前复权、估值、财务指标和风险描述子是带完整上游快照的确定性派生表。
7. 价格单位统一为元/股，成交量为股，金额为元，比例和利率存十进制小数；来源原单位同时在raw证据和转换元数据中保留。
8. 新字段兼容增加走schema小版本；主键、单位、PIT或语义变化走主版本或新 `dataset_id`。

## 4. 20项核心合同

| 分组 | 数据集 | 主要事实 |
|---|---|---|
| 身份与行情 | CORE-01～08 | 证券主数据、日历、未复权日行情、公司行动、前复权投影、可交易性、股本/自由流通、估值 |
| 指数与行业 | CORE-09～12 | 多提供商指数主数据、PIT成分权重、证监会/申万多口径行业、指数日行情与收益变体 |
| 财务与事件 | CORE-13～18 | 财务事实长表、可重建指标、业绩预告/快报、审计意见、分红权利事件、主营分部 |
| 基准与风险 | CORE-19～20 | 短端国债和银行间利率、可复现的行业/规模/Beta/波动/流动性/动量原始描述子 |

CORE-13采用会计事实长表，不把数百个会计科目固化成不可演进的超级宽表；概念身份、报表上下文、合并口径、期间、单位、值、公告和修订共同确定事实。CORE-20只发布L1原始风险描述子；缩尾、横截面标准化、中性化和因子收益估计留在L2。

## 5. 来源与许可裁决

- 交易所、巨潮、证监会、中国结算、指数公司、人民银行、中国货币网和中债是权威入口。
- 上交所和深交所官方说明均存在授权行情产品；因此日行情字段可以冻结，但批量历史摄取必须先登记具体产品、端点、费用和内部保存条款。
- 指数目录元数据可以先生成候选清单；行情、收益变体、历史成分和权重逐提供商、逐指数登记历史可得性和许可。当前成分不得回填历史。
- 证监会 `JR/T 0020-2024` 是行业结构官方基线；它不提供完整逐证券历史归属。申万分类是用户指定研究主口径，但公开下载中心不自动证明历史成员和内部长期保存许可。
- 中债和中国货币网页面可公开查看，但两者对数据使用另有许可声明；CORE-19在取得明确许可前保持采集阻断。
- AKShare仅是采集适配器；其代码许可证不替代底层端点的数据许可。Tushare本批未获Token或付费授权，只能保留为未来校准候选。

这里的许可状态是工程准入闸门，不是法律意见。每个实际端点在D12A试点前仍需保存条款版本、访问方式、允许的本地保存/内部共享范围和证据哈希。
